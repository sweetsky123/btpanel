### 安装命令，默认安装`11.0`版本，请通过更新命令进行更新

```
wget https://github.com/sweetsky123/btpanel/releases/download/11.0/install_latest.sh && bash install_latest.sh && rm install_latest.sh
```

如果没有wget，也可以使用curl

```
curl -O https://github.com/sweetsky123/btpanel/releases/download/11.0/install_latest.sh && bash install_latest.sh && rm install_latest.sh
```



### 更新面板至最新（11.4）版本，所有版本包括低版本都可以用此命令更新。

```
wget https://github.com/sweetsky123/btpanel/releases/download/11.4/update_panel.sh && bash update_panel.sh && rm update_panel.sh
```

```
wget https://github.com/sweetsky123/btpanel/releases/download/11.4/update_panel.sh && bash update_panel.sh && rm update_panel.sh
```
